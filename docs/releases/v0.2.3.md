## Separate modules, installed for you

`0.2.3` is the modular install. Every package is its own tarball, and each tarball declares its
internal dependencies as **tarball URLs on the `releases` branch** — so installing one module
pulls the rest by itself, one package at a time.

```bash
npm install https://github.com/sieteminerva/AIO-UI/releases/download/v0.2.3/aio-ui-form-0.2.3.tgz
```

That command leaves `node_modules/@aio-ui` with **eight separate modules**:

```text
base  core  form  http-service  input  message  module-loader  utilities
```

Nothing is embedded, nothing is duplicated, and no `registry.npmjs.org` lookup is attempted for
the `@aio-ui/*` family. Install `aio-ui-table` instead and you get table's own closure; install a
leaf like `aio-ui-masonry` and its tarball is the only thing added.

The bundled variant still exists (`node scripts/release.mjs --apply --bundle`), but it is the
fallback for a single-URL-only consumer, not the default.

### What changed since `0.2.2`

- **Mode B is the default**: internal edges are tarball URLs, not peers and not embedded copies.
  `bundledDependencies` is gone unless `--bundle` is used.
- **Form and input speak up**: a missing sub-module names itself with a fix, emits
  `moduleMissing`, and throws where a warning would leave a hole (declared `actions`, `files`
  policy). `@aio-ui/form/adapters` is the full nine-module stack; `@aio-ui/form` depends on
  `@aio-ui/input`.
- **Release artefacts are visible**: orphan branch `releases`, checked out at `./releases`,
  carries the unpacked tree and every version folder.

### Try it

```html
<script type="importmap">
  {
    "imports": {
      "@aio-ui/core": "https://cdn.jsdelivr.net/gh/sieteminerva/AIO-UI@v0.2.3/packages/core/dist/index.js",
      "@aio-ui/form": "https://cdn.jsdelivr.net/gh/sieteminerva/AIO-UI@v0.2.3/packages/components/form/dist/index.js",
      "@aio-ui/form/Form.css": "https://cdn.jsdelivr.net/gh/sieteminerva/AIO-UI@v0.2.3/packages/components/form/dist/Form.css"
    }
  }
</script>
```

### Numbers

- **40 packages**, fixed versioning at `0.2.3`
- **1.18 MB** of tarballs for the whole family (mode B)
- `npm run verify` → 83 files, 757 tests passed
- Empty project, one tarball, eight modules installed, cache populated only by those tarballs
