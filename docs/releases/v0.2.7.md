# v0.2.7 — the header block, the PascalCase sheets

Pre-release. **38 packages** (was 37): `@aio-ui/header` joins the family as the article heading
block. Beside it, the class files that `v0.2.6` still served in kebab-case are now **PascalCase**
and their sheet specifiers mirror the file names, so a browser on a case-sensitive filesystem
resolves every one. The row layout, the compact menu, the toggle field and the demo sidebar each
got a fix.

## Breaking (vs `v0.2.6`)

- **Stylesheet and builder files are PascalCase.** `input.css` → `Input.css`,
  `controls.css` → `InputControls.css`, `id-address.css` → `IdAddress.css`, and the builder
  `id-address-builder.ts` → `IdAddressBuilder.ts`. Every sheet specifier now mirrors its file
  (`@aio-ui/input/Input.css`, `@aio-ui/input/InputControls.css`, `@aio-ui/id-address/IdAddress.css`).
  `v0.2.6` still serves the lowercase names; this tag does not.

## Migration

```diff
-import "@aio-ui/input/input.css";
-import "@aio-ui/input/controls.css";
-import "@aio-ui/id-address/id-address.css";
+import "@aio-ui/input/Input.css";
+import "@aio-ui/input/InputControls.css";
+import "@aio-ui/id-address/IdAddress.css";
```

## Added

- **`@aio-ui/header` — the article heading block.** One `header` root draws icon, title, subtitle
  and an optional meta line; `size` (`huge | normal | medium | small`) picks the heading level so a
  page keeps one outline. `iconPosition` (`top | left | right | bottom`) is a placement, not a
  re-order; the DOM order never moves.
- **`appearance` is a shape, never a palette.** `normal | bordered | block | editorial` decides how
  the stack sits; every colour still comes from a `--header-*` token, so a theme retunes the result.
- **Two ink doors.** `config.color` (`title`, `subtitle`, `icon`, `metadata`, `block`, `border`)
  writes each part's token on the root; `config.selectors[key].color` is the general door every
  builder offers.
- **A selector's own colour wins over the sheet.** `Base._applyNodeAttributes` writes an inline
  `color` for `config.selectors[key].color`, so one instance can escape the token without a theme.

## Fixed

- **A toggle field measures like a plain field.** `Form.css` keeps the toggle child's `display`
  off the row's block, so its label sits beside the switch and no longer pins a height.
- **The compact menu is in-flow.** A compact submenu no longer floats as an absolute popover; the
  sheet draws it inline, and a touch tap opens a branch while the logo stays an icon.
- **A column divides evenly.** An undeclared `wide` now takes an equal slice of its line, and a
  row holding a toggle no longer becomes a grid.
- **The demo sidebar stays closeable after a resize.**
