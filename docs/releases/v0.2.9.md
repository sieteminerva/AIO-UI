# v0.2.9 — the icon channel, `iFieldNode`, and a form that honours min-height

**38 packages**, all at `0.2.9`. This release carries the work that b112/b113 landed after `v0.2.8`
was tagged: the field schema collapses to one name, the icon channel links real glyph files, a tab's
button and panel finally share one id, and `config.minHeight` reaches the form root instead of a
container that never renders.

## Why a new version and not a refreshed `v0.2.8`

`v0.2.8` was already served by jsDelivr (`cache-control: immutable, max-age=31536000`) before the
b112/b113 bytes existed. jsDelivr pins a tag to the first commit it sees and ignores purges, so
re-publishing `0.2.8` would have moved the ref while the CDN kept answering the old tree — the same
trap that produced `v0.1.1`. `v0.2.8` stays exactly as served; `v0.2.9` is the fixed tree.

## Breaking (vs `v0.2.8`)

- **`AnyInputSchema` is gone.** The field schema is one name again, `iFieldNode`; `iFieldSeed` is the
  builder's loose door. A caller that imported `AnyInputSchema` must switch to `iFieldNode`.
- **The Apps Script note is public** as `iAppsScriptFieldNode`: `range` is a named range, allowed
  only on the types that choose it; `config.sheet` / `cell` / `skipped` are the storage address.
- **`icons.css` is links only.** The `<i>` rule moved to `src/components.css`, the glyph files
  travel in `imgs/` (112 glyphs), and the `close` glyph is retired in favour of `cross` — right
  arrows are mirrors, not separate files. A sheet that relied on the inline `icon.css` block must
  load the linked sheet.
- **A tab's button and panel share one id pair.** `onTabChanged` / `onContentLoaded` are fed, and
  `active` falls back to the first tab instead of rendering an empty panel.

## Fixed

- **`config.minHeight` reaches the form.** It wrote `--form-min-height` on the root while only the
  body rule read it, so the token sat unused; the declaration now sits on `&` / `form.form` and the
  body keeps its own fallback.
- **A tab button carries ONE `btn-label` span**, with the record's `title` as its tooltip — the
  second span was always empty.
- **`copy` copies a one-control scope's value**, not its payload.
