# v0.2.4 — one core, one bundle

Pre-release breaking change. The framework stops pretending to be three packages.

## Breaking

- **`@aio-ui/app` is gone.** `AioApp`, `AppStorage`, `blockToNode`, `pageToNode`, `normalizeRoute`
  and `isPageDocument` are exported from `@aio-ui/core`; `@aio-ui/core/app` is the topic entry.
  The page/content contracts (`iPageContent`, `iPageController`, `iPageContext`,
  `iPageReadyContext`, `iComponentRoute`, …) are core types now.
- **`@aio-ui/frameworks` is gone.** There is no aggregator kit: import from `core` and `base`.
- **`@aio-ui/core` installs `@aio-ui/styles`.** The stylesheet is not imported by JS, but the edge
  exists so `npm i @aio-ui/core` can never leave an app unstyled.
- **Manifests declare what their source imports.** `scripts/edges.mjs` derives every
  `@aio-ui/*` edge; `npm run check:edges` fails when a manifest disagrees with its source.
  Components declare `base`/`core` as peers, and `skeleton` is never repeated.

## Migration

```diff
-import { AioApp, AppStorage } from "@aio-ui/app";
+import { AioApp, AppStorage } from "@aio-ui/core";

-import type { iPageContent } from "@aio-ui/app";
+import type { iPageContent } from "@aio-ui/core";
```

The import map loses `@aio-ui/app` and `@aio-ui/frameworks`; both are already answered by
`@aio-ui/core`. Package count: 40 → 38.

- **Three component packages are spelled like their builder.** `@aio-ui/fabmenu` →
  `@aio-ui/fab-menu`, `@aio-ui/modeswitcher` → `@aio-ui/mode-switcher`, `@aio-ui/pricingcard` →
  `@aio-ui/pricing-card`. Folder, package name and registry key now agree; the CSS subpaths
  (`/FabMenu.css`, `/ModeSwitcher.css`, `/PricingCard.css`) are unchanged.

## Added

- **`@aio-ui/dom-renderer`** (`packages/modules/dom-renderer`) — the renderer alone, for projects
  migrating without the framework. `src/DOMRenderer.ts` is generated by
  `scripts/build-renderer-kit.mjs` from `packages/core/src/DOMRenderer/`, imports nothing, and is
  guarded twice: `check:kit` fails a stale copy, `__tests__/kit.test.ts` fails a behavioural drift
  against core. Package count: 38 → 39.
- `npm run build:bundle` (`scripts/build-bundle.mjs`) builds the two-link CDN pair:
  `aio-ui.js`, `aio-ui.min.js`, `aio-ui.css`, `aio-ui.min.css`. The script is an IIFE whose
  default export is the namespace — `AioUI.DOMRenderer`, `AioUI.AccordionBuilder`,
  `AioUI.FormBuilder`, … plus `AioUI.version` and `AioUI.packages`. A duplicate export name
  across packages fails the build instead of silently overwriting.
