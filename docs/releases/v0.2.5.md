# v0.2.5 — the 37-package tree ships

Pre-release. This is the first tag that publishes the post-refactor tree: **37 packages, 76
subpath rows**. The `@v0.2.4` tag still serves the old 39-package surface — v0.2.5 is the release
that lands the one-door-per-package refactor, and the first in which **every package carries a
README** and a per-package version.

`store` / `profile` / `blog` still do not exist, so the official release waits for them.

## Breaking (vs the published `@v0.2.4` tag)

- **`@aio-ui/rating` is gone.** Use `@aio-ui/input` or `@aio-ui/message` for feedback; the rating
  control is not replaced one-for-one. Package count: 39 → 37.
- **The `@aio-ui/modules` kit is gone.** There is no aggregator kit; import the individual
  `@aio-ui/<module>` package you need.
- **One door per package.** A component's adapters and sub-modules are exported from its root (and
  its own component subpath), never a separate `/module` or `/adapters` door.
- **Core's type-only subpaths collapse into the root.** Type imports come from `@aio-ui/core`.

## Migration

```diff
-import { Rating } from "@aio-ui/rating";
+// no replacement — pick @aio-ui/input or @aio-ui/message

-import type { iComponentSchema } from "@aio-ui/core/types";
+import type { iComponentSchema } from "@aio-ui/core";
```

The import map loses `@aio-ui/rating` and the `@aio-ui/modules` kit; every other door is answered
by the package root or its component subpath.

## Added

- **A README in every package.** `release-doc.mjs --readme --apply` writes an `<!-- install:begin
  -->` block naming the package version, its tarball URL, the CDN module URL and its stylesheet, so
  `37/37` packages now document how to install them (was 29 of 37).
- **One tag, one version per package.** `0.2.5` moves the whole family at once, but the mechanism
  is per-package: a later patch can raise one package alone and `release.mjs --strict` reuses the
  unchanged bytes instead of repacking them.
