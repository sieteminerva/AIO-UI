# v0.2.8 — the icon channel in the bundle

Pre-release. **38 packages** (all at `0.2.8`). The icon channel that landed in b109 reaches the
published artefacts: the bundled sheet now **links** its 107 glyphs instead of inlining them, and
`imgs/` ships beside `aio-ui.css` at the branch root. The batch also carries the multistep and
action-seam fixes plus the compact code panel that landed after `v0.2.7`.

## Breaking (vs `v0.2.7`)

- **The bundled CSS links its glyphs.** `aio-ui.css` / `aio-ui.min.css` are now 328.4 / 173.7 kB
  (was 530.1 / 379.2 kB): every `mask-image` is `url("./imgs/<name>.svg")`, and the folder travels
  with the four bundle files. A site that copies the four files to its own host must copy `imgs/`
  beside them; a site on the CDN needs nothing new.
- **`registry.json.bundle.imgs`** records `{ folder, count, sample }`, so `check:live` can fetch
  one glyph and prove the folder reached jsDelivr.

## Migration

```diff
-<link rel="stylesheet" href="…/aio-ui.min.css">
+<link rel="stylesheet" href="…/aio-ui.min.css">   <!-- unchanged -->
+# a self-hosted copy needs the folder beside it:
+cp imgs/ /your/static/root/imgs/
```

## Added

- **`imgs/` at the branch root** — 107 glyphs, each referenced by one relative `url()`; the 13
  authored `data:` glyphs in the source sheets (spinner, select arrows) stay as written.
- **A build gate for the stylesheet** — `build-bundle.mjs` fails when a glyph is inlined, a `url()`
  is root-absolute, a link has no file beside the CSS, or the link count disagrees with the folder.
  `orchestrator/__test__/release.test.ts` re-runs the same scan against the written artefact.

## Fixed

- **The bundle stylesheet no longer overwrites itself.** Every asset was named `aio-ui.css`, so
  with 107 emitted glyphs the last SVG replaced the stylesheet; the artefact was 8 kB of raw
  `<svg>`. Assets are now `imgs/[name][extname]`, the stylesheet keeps its name, and the CSS build
  runs with `assetsInlineLimit: 0` and `base: "./"`.
- **Multistep no longer assumes a step sits at schema index 0** (`attach()` mounts the smallest
  held index; `isFirst`/`isLast` come from the steps that exist; a one-step form gets Submit).
- **The input + actions composite keeps one hairline at the seam** and its outer radius; the
  blanket `border-radius: 0 !important` is gone.
- **`CodeBlock` resets the global `section` padding** it inherited and gained
  `config.appearance = normal | compact`.
